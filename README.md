# Super Blog Automation (n8n)

n8n workflow project for automating blog ideation, drafting, and publishing steps.

## What this repo contains
- `Code` - exported/working automation logic
- `n8n Super Blog Automation - n8n.png` - workflow reference image

## Employment-Ready Standards
This repo includes baseline docs, CI, and handoff checklists so collaborators can onboard quickly.

## Setup
1. Import workflow into n8n.
2. Configure required credentials in n8n credential manager.
3. Use `.env.example` keys as naming baseline for external env vars.

## Ops Docs
- `docs/WORKFLOW_RUNBOOK.md`
- `docs/HANDOFF_CHECKLIST.md`

## Security
- Keep API keys in n8n credentials/secrets manager.
- Do not commit live tokens or webhook secrets.
